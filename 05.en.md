## Guidance for Individual Developers

### Choosing a category

The proposed category is **Tools → Health Management**. The official table checked in the previous round covers health-related records or tests, with examples such as height, weight, and personal body management records. The qualifications column shows “/”. The options available to this individual account and the final category remain to be verified. Alternatives are Tools → Memo and Tools → Bookkeeping. [WeChat Mini Program service categories](https://developers.weixin.qq.com/miniprogram/product/material/?lang=zh_CN)

Check the relevant qualifications if the Mini Program offers access to medical care, internet hospitals, medication, medical devices, or online consultations. Its pages, description, and tags should accurately describe what it does.

### Three common review blockers for individuals

1. **A category unavailable to the account type.** Select a category open to individual developers. Make the main function easy to find, and keep the tags, description, and category consistent.
2. **Incomplete filing.** Publishing without a completed filing fails with error code **86369**, which says the Mini Program must complete filing before going live. Follow the console’s instructions for individual filing materials and service content indicators. Use the same entity for both registration and filing. Start filing during development so it is ready when the code clears review.
3. **Privacy or incomplete functionality.** Clearly disclose data collection and obtain consent. Verify which features work if the user declines permissions. If the Mini Program has accounts, provide an easy-to-find account deletion flow and give reviewers a test account that can access all features. Submit a finished build with responsive controls and without test content or crashes.
